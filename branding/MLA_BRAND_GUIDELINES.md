## 1. 品牌策略

### 1.1 品牌定位

| 维度 | 定义 |
|---|---|
| **品类** | AI 赋能教育科技 / 多智能体学习助手 |
| **受众** | 大学生、自学者、知识工作者 |
| **产品功能** | 多 Agent 协作驱动的智能学习平台 |
| **情感承诺** | 让知识获取更高效、更有条理、更个性化 |
| **信任层级** | 高 — 教育工具需要可靠、严谨 |
| **文化定位** | 现代、理性、清晰、不冰冷 |

### 1.2 品牌三个关键词

1. **连接 (Connect)** — 碎片知识连成网络，Agent 协同工作
2. **生长 (Grow)** — 知识体系逐步构建，能力持续进化
3. **清晰 (Clarity)** — 复杂概念变得可视、可理解

### 1.3 品牌个性

```
严谨的学者 — 但不刻板
聪明的助手 — 但不说教
高效的工具 — 但不冷漠
```

### 1.4 视觉世界

```
┌─────────────────────────────────────────────┐
│  克制的蓝色 · 清晰的层级 · 充裕的留白          │
│  精准的排版 · 一致的间距 · 克制的动效           │
│  专业感优先 · 信息层次清晰 · 无视觉噪音         │
└─────────────────────────────────────────────┘
```

## 2. Logo 标识系统

### 2.1 设计原则

- **扁平化** — 纯文字排版，无拟物图形
- **极简** — 仅依靠字体、字重、间距传达品牌感
- **易维护** — 不需要专门的图形设计工具即可复现，开发成本最低
- **有辨识度** — 通过字母间距和字重对比建立独特性

### 2.2 主标识：纯文字 Wordmark

```
MLA

M   L   A
```

**设计逻辑**：
- 品牌名 "MLA" 三个字母是 Multiple Learning Agent 的首字母缩写
- M 代表 Multiple（多智能体协作）
- L 代表 Learning（学习方法论驱动）
- A 代表 Agent（AI Agent 技术底座）

### 2.3 标识变体

| 变体 | 排版 | 用途 |
|---|---|---|
| **完整标识** | `MLA` 大字 + 下方小字 `智学引擎` | 侧边栏顶部、登录页、设置页 |
| **横排标识** | `MLA 智学引擎` 单行 | Header、Footer |
| **纯文字标识** | `MLA` 仅三个字母 | Favicon 区域、小空间场景、移动端 |

> 无图形图标——标识本身即排版。这与 Stripe、Notion、Vercel 的设计哲学一致。

### 2.4 标识构建规范

```
完整标识（竖排）:

    M  L  A           ← 字重 800，字间距 -0.03em，字号 20px / Inter
    智 学 引 擎        ← 字重 500，字间距 +0.08em，字号 10px，色值 gray-400
                       ← 与上方 MLA 间距 2px

横排标识:

    MLA  智学引擎      ← MLA 字重 700 / 间隔 8px / 智学引擎 字重 500 gray-400
```

### 2.5 安全空间

Logo 周围最小安全空间 = MLA 中大写 M 字母高度的 1 倍。

```
    ←── 1×H ──→
    ┌──────────┐
    │   MLA    │  ← H = 大写 M 高度
    │  智学引擎  │
    └──────────┘
    ←── 1×H ──→
```

### 2.6 当前应用建议

- **侧边栏顶部**：竖排完整标识（MLA + 智学引擎），左对齐
- **Favicon**：直接使用 "MLA" 三个字母的 SVG（白字透明底或蓝底白字）
- **浏览器标签页标题**：`MLA - 智学引擎`
- **不需要**绘制任何图形 Logo — 文字即标识

## 3. 色彩体系

### 3.1 设计参考

本色彩体系参考了以下主流网站/产品的配色逻辑：

| 参考产品 | 品类 | 主色 | 中性色 |
|---|---|---|---|
| **Coursera** | 在线教育 | `#0056D2` 深蓝 | 白/浅灰 |
| **Khan Academy** | 在线教育 | `#0D7CBF` 中蓝 | 白/浅灰 |
| **Notion** | 生产力 | 几乎无色，黑白为主 | 极简灰 |
| **Linear** | 项目管理 | `#5E6AD2` 靛蓝 | 深色面板 |
| **GitHub** | 开发者工具 | `#2DA44E` 绿色点缀 | 灰白系统 |
| **Vercel** | 开发者平台 | 黑白为主，蓝色点缀 | 纯黑白 |
| **Figma** | 设计工具 | 无色，UI 靠灰阶 | 多级灰阶 |

**共同规律**：没有一个主流产品使用高饱和暖色（橙/琥珀/金）作为 UI 主色。优秀的 UI 主色应当是**克制的、可用于大面积文字和交互元素的、与灰阶系统协调的**。蓝色系之所以被最广泛使用，是因为它天然兼容 UI 中的信息层次——蓝色文字在白色背景上可读性高、蓝色按钮视觉重量适中、蓝色不随文化变化产生歧义。

### 3.2 色彩哲学

```
颜色在 UI 中的角色不是"装饰"，而是"信息层次"。
主色用于引导注意力和表达交互状态，不是用于填充背景。
UI 的 95% 面积应该使用中性色。
```

### 3.3 主色板：克制蓝

```
         50    100    200    300    400    500    600    700    800    900
        ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐
品牌蓝   ██   ██   ██   ██   ██   ██   ██   ██   ██   ██
        └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘
        浅背景 标签   选中   边框  次要   主色   Hover  Active  深文   最深
```

| 色阶 | 色值 | 用途 |
|---|---|---|
| `blue-50` | `#EFF6FF` | 最浅背景、信息卡片底色 |
| `blue-100` | `#DBEAFE` | 选中态背景、标签底色 |
| `blue-200` | `#BFDBFE` | 次级选中态 |
| `blue-300` | `#93C5FD` | 聚焦光环 (focus ring) |
| `blue-400` | `#60A5FA` | 辅助强调元素 |
| **`blue-500`** | **`#3B82F6`** | **品牌主色** — 主按钮、链接、活跃态 |
| `blue-600` | `#2563EB` | Hover 态加深 |
| `blue-700` | `#1D4ED8` | Active 态按压 |
| `blue-800` | `#1E40AF` | 深色强调文字 |
| `blue-900` | `#1E3A8A` | 最深强调 |

**为什么选择 `#3B82F6`（Tailwind Blue-500）？**

1. **广泛验证** — 这是 Tailwind CSS 的默认蓝色，被数以万计的产品使用，是经过充分实战检验的色彩
2. **亮度适中** — 不像 Ant Design 默认蓝 `#1677FF` 那样亮、刺眼；在白色背景上的对比度足够（约 4.5:1，符合 WCAG AA 大文字标准）
3. **兼容中文** — 在中文界面中，较亮的蓝色会让文字显得"飘"；`#3B82F6` 足够沉稳
4. **不过度饱和** — 饱和度为 85%，低于 AI 产品中常见的 95-100% 饱和度蓝色
5. **易于延展** — 可以生成完整 50-900 色阶，每个色阶都有明确用途

### 3.4 中性色板：冷灰 Slate

```
         50    100    200    300    400    500    600    700    800    900
        ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐
中性灰   ██   ██   ██   ██   ██   ██   ██   ██   ██   ██
        └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘
        页面  侧栏   边框   分割   禁用   辅助   次要   正文   标题   最深
        背景   背景                   文字   文字   文字
```

| 色阶 | 色值 | 用途 |
|---|---|---|
| `gray-50` | `#F8FAFC` | 页面背景 |
| `gray-100` | `#F1F5F9` | 侧边栏背景、卡片次级底色 |
| `gray-200` | `#E2E8F0` | 边框、分割线 |
| `gray-300` | `#CBD5E1` | 输入框边框、禁用态边框 |
| `gray-400` | `#94A3B8` | 禁用文字、占位符 |
| `gray-500` | `#64748B` | 辅助说明文字 |
| `gray-600` | `#475569` | 次要正文 |
| `gray-700` | `#334155` | 正文文字 |
| `gray-800` | `#1E293B` | 标题文字 |
| `gray-900` | `#0F172A` | 最深标题、强调文字 |

**为什么用冷灰（Slate）而非暖灰？**

暖灰（如 Tailwind Stone/Warm Gray）带有黄/红色偏，与蓝色主色共同使用时会产生"冷暖冲突"，视觉上不干净。冷灰（Slate）带有微蓝底色，与品牌蓝色天然协调，形成统一的"清爽理智"感受。这也是 Notion、Linear、GitHub 等产品使用冷灰而非暖灰的原因。

### 3.5 语义色彩

| Token | 色值 | 用途 |
|---|---|---|
| `success` | `#16A34A` | 成功状态、完成标记 |
| `success-bg` | `#DCFCE7` | 成功状态背景 |
| `warning` | `#D97706` | 警告状态（仅保留此一处暖色） |
| `warning-bg` | `#FEF3C7` | 警告状态背景 |
| `danger` | `#DC2626` | 危险操作、删除按钮 |
| `danger-bg` | `#FEE2E2` | 危险状态背景 |
| `info` | `#3B82F6` | 信息提示（与主色一致） |
| `info-bg` | `#EFF6FF` | 信息状态背景 |

### 3.6 配色比例

```
70% — 中性灰 (页面背景、卡片、边框、分割线、辅助文字)
20% — 白色 (内容区域、输入框、卡片表面)
 7% — 品牌蓝 (按钮、链接、活跃态、选中标记)
 3% — 语义色 (成功/警告/危险的彩色标签和状态图标)
```

### 3.7 渐变色

**本设计体系不推荐使用渐变**。如确需使用，仅在以下场景：

| 场景 | 用法 |
|---|---|
| 登录页背景 | 纯色 `gray-50` 或极淡的蓝灰渐变（不明显） |
| 主按钮 Hover | 微妙的亮度变化，通过 `blue-500 → blue-600` 过渡 |
| 图表 / 数据可视化 | 单色不同透明度，不使用彩虹色 |

## 4. 字体系统

### 4.1 字体选型

| 角色 | 字体 | 字重 | 用途 |
|---|---|---|---|
| **UI 标题 / 正文** | Inter | 400-800 | 全站英文与数字 |
| **中文正文** | PingFang SC | 400-600 | 中文界面文字 |
| **等宽字体** | JetBrains Mono | 400-500 | 代码块、数据展示 |
| **数字** | Inter `tabular-nums` | 600-700 | 统计数据、表格数字 |

### 4.2 字体级联

```css
font-family: 'Inter', -apple-system, BlinkMacSystemFont,
             'PingFang SC', 'Microsoft YaHei',
             'Noto Sans SC', sans-serif;
```

### 4.3 排版层级

| 层级 | 字号 | 行高 | 字重 | 字间距 | 用途 |
|---|---|---|---|---|---|
| **H1** | 24px | 1.2 | 700 | -0.025em | 页面标题 |
| **H2** | 18px | 1.25 | 600 | -0.015em | 区块标题 |
| **H3** | 15px | 1.35 | 600 | 0 | 卡片标题 |
| **Body** | 14px | 1.5 | 400 | 0 | 正文 |
| **Body-S** | 13px | 1.5 | 400 | 0 | 辅助说明、列表项 |
| **Caption** | 12px | 1.4 | 500 | 0 | 标签、角标 |
| **Overline** | 10px | 1.3 | 600 | +0.05em | 分类标签 |

### 4.4 排版原则

- 标题使用 sentence case（首字母大写即可，非每个词首字母大写）
- 正文行宽不超过 65 个字符（中文约 32 字）
- 所有数字使用 `font-variant-numeric: tabular-nums` 保证对齐
- **禁止在 UI 中使用 Emoji**
- 标题使用 `text-wrap: balance` 防止孤行

## 5. 图标体系

### 5.1 图标规格

- **基准网格**：24 × 24px
- **描边宽度**：1.8px（统一）
- **端头样式**：`stroke-linecap: round; stroke-linejoin: round`
- **颜色**：使用 `currentColor` 继承父级文字颜色
- **风格**：线框描边（outline style），不使用面性图标

### 5.2 图标来源

推荐使用项目已集成的 `@ant-design/icons` v6 图标库，无需额外引入第三方图标集。

所有 antd 图标默认满足 24px 网格和统一的描边规格。

## 7. 圆角与阴影

### 7.1 圆角

| Token | 值 | 用途 |
|---|---|---|
| `radius-sm` | 6px | 输入框、标签、小按钮 |
| `radius-md` | 8px | 图标容器、列表项 |
| `radius-lg` | 12px | 卡片、面板 |
| `radius-xl` | 16px | 模态框 |
| `radius-full` | 9999px | 头像、标签胶囊、浮动按钮 |

**原则**：外层大圆角，内层小圆角，避免全站统一圆角。

### 7.2 阴影

| Token | 值 | 用途 |
|---|---|---|
| `shadow-xs` | `0 1px 2px rgba(15,23,42,0.04)` | 微分层 |
| `shadow-sm` | `0 1px 3px rgba(15,23,42,0.06)` | 下拉菜单 |
| `shadow-md` | `0 4px 12px rgba(15,23,42,0.08)` | Hover 卡片 |
| `shadow-lg` | `0 12px 28px rgba(15,23,42,0.10)` | 模态框 |
| `shadow-xl` | `0 20px 48px rgba(15,23,42,0.12)` | 全屏覆盖层 |

**关键**：阴影色使用 `gray-900` 的 rgba 值，不使用纯黑 `rgba(0,0,0,x)`。

## 8. 动效语言

### 8.1 过渡参数

| Token | 值 | 用途 |
|---|---|---|
| `ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 所有交互动画 |
| `duration-fast` | `150ms` | 微交互（hover/active/focus） |
| `duration-normal` | `200ms` | 标准过渡 |
| `duration-slow` | `300ms` | 入场动画、布局切换 |

### 8.2 交互状态链

每个可交互元素覆盖以下状态：

```
rest → hover → active → focus → disabled
```

| 状态 | 效果 |
|---|---|
| rest | 默认样式 |
| hover | 背景微变 + 阴影提升 + 位移 -1px |
| active | `scale(0.97)` 按压反馈 |
| focus | 2px `blue-300` outline ring |
| disabled | `opacity: 0.4` + `pointer-events: none` |

### 8.3 页面加载入场

卡片从上到下 stagger 入场：`fadeSlideUp` 动画，每层延迟 50ms。

## 9. UI 应用规范

### 9.1 侧边栏

```
┌─────────────┐
│   MLA       │  ← 侧边栏顶部：纯文字 Logo，左对齐
│   智学引擎    │
│─────────────│
│  概览        │
│  · 仪表盘   │  ← 活跃项：白色背景 + shadow-xs 浮起
│  · 课程     │  ← 默认项：透明背景
│     ...     │
└─────────────┘
```

- **背景**：`gray-100`（`#F1F5F9`）
- **活跃项**：白色背景 + `shadow-xs` + 1px `gray-200` 边框
- **默认项**：透明，hover 时 `gray-200` 背景
- **与页面背景关系**：侧栏 `gray-100`，页面 `gray-50`，通过一级明度差建立层次

### 9.2 顶部 Header

- 毛玻璃效果：`background: rgba(255,255,255,0.8); backdrop-filter: blur(12px)`
- 底部 1px `gray-200` 边框
- sticky 定位
- 面包屑导航
- 顶部 Header 的最右侧未用户的登录状态组件
  - 若用户登录则显示用户头像和昵称，点击可弹出“个人中心”、“退出登录”
  - 未登录则标识“未登录”，点击可进行登录

### 9.3 卡片

- 背景：白色
- 边框：1px `gray-200`
- 圆角：`radius-lg`（12px）
- 默认无阴影
- Hover：`shadow-md` + 边框加深至 `gray-300` + 上移 -1px

### 9.4 按钮层级

| 层级 | 样式 | 用途 |
|---|---|---|
| **Primary** | 蓝色实底 `blue-500` + 白色文字 | 主操作 |
| **Secondary** | 白色 + 蓝色边框 + 蓝色文字 | 次要操作 |
| **Ghost** | 无边框无背景 + 蓝色文字 | 最弱操作 |
| **Danger** | 红色实底 + 白色文字 | 删除等危险操作 |

### 9.5 表单

- 输入框高度：36px
- 圆角：`radius-sm`（6px）
- 聚焦态：1.5px `blue-500` 边框 + `0 0 0 3px rgba(59,130,246,0.15)` 光环
- 错误态：`danger` 色边框 + 错误提示
- 禁用态：`gray-100` 背景 + `gray-400` 文字

### 9.6 空状态

```
┌──────────────────────────┐
│                          │
│         [图标 64px]       │  ← gray-300 色大图标
│                          │
│       暂无学习课程         │  ← H2，gray-800
│   上传第一份文档开始学习    │  ← Body，gray-500
│                          │
│       [＋ 创建课程]        │  ← Primary 按钮
│                          │

```

- **卡片级**：Skeleton 匹配卡片结构
- **列表级**：3-5 条交错长短的 Skeleton 行
- **按钮级**：旋转 spinner + 禁用态

## 10. 禁止事项

### 绝对禁止

| 禁止行为 | 原因 |
|---|---|
| ❌ 使用 Emoji 作为界面元素 | 风格不统一，缺乏品牌感 |
| ❌ 使用蓝紫 "AI 渐变" (如 `#667eea → #764ba2`) | AI 产品最泛滥的设计套路 |
| ❌ 使用纯黑 `#000000` | 刺眼，缺乏质感 |
| ❌ 在 UI 中使用渐变背景 | 干扰信息获取 |
| ❌ 超过 2 个强调色同时出现在同一视图 | 视觉噪音 |
| ❌ 统一使用相同圆角 | 缺乏层次感 |
| ❌ 阴影使用纯黑 `rgba(0,0,0,x)` | 使用 gray-900 的 rgba |
| ❌ 未统一粗细/尺寸的图标混用 | 业余感 |
| ❌ 内联样式与 CSS 类混用 | 维护噩梦 |
| ❌ 彩虹色图表 | 使用品牌蓝 + 灰阶 |

### 谨慎使用

| 行为 | 条件 |
|---|---|
| ⚠️ 动画 | 有明确目的，遵守 `prefers-reduced-motion` |
| ⚠️ 装饰元素 | 仅 noise 微纹理，不明显干扰内容 |
| ⚠️ 高饱和色 | 仅用于语义状态标签 |
